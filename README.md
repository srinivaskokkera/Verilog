# Verilog Workshop

A collection of digital electronics and RTL design projects implemented using **Verilog HDL** and simulated using **ModelSim**.

## Projects

| Project | Description |
|---|---|
| ALU 4-bit | 4-bit Arithmetic Logic Unit |
| D Flip-Flop | D Flip-Flop implementation |
| Half Adder | Half Adder using Verilog |
| Half Adder Flip-Flop | Sequential logic design |
| Elevator | Elevator control system |
| Washing Machine | Washing machine controller |
| RISC-V 5-Stage | 5-stage pipelined RISC-V processor |

## Tools & Technologies

- Verilog HDL
- ModelSim
- Digital Logic Design
- RTL Design
- Functional Simulation

## How to Run

1. Clone this repository.
2. Open ModelSim.
3. Create or open a simulation project.
4. Add the Verilog source files and testbench.
5. Compile the design.
6. Run the simulation and observe the waveforms.

## Purpose

This repository documents my practical learning and implementation of digital logic circuits, RTL design, and processor architecture using Verilog HDL.
